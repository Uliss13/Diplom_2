# Diplom_2: Автотесты API Stellar Burgers

Проект по автоматизации тестирования API учебного сервиса «Stellar Burgers» (Яндекс.Практикум, дипломный проект, часть 2).

## Стек
- Python 3.9
- pytest
- requests
- allure-pytest

## Структура проекта
- `api_client.py` — методы для отправки HTTP-запросов (с шагами Allure).
- `conftest.py` — фикстуры pytest (создание/удаление пользователя, получение ингредиентов).
- `data.py` — константы статус-кодов, текстов ошибок и тестовые данные.
- `helpers.py` — генерация случайных данных (email, имя, пароль).
- `urls.py` — эндпоинты API.
- `tests/` — тесты, разбитые по ручкам:
  - `test_create_user.py` — регистрация пользователя.
  - `test_login_user.py` — авторизация.
  - `test_create_order.py` — создание заказа.
- `allure-report/` — сгенерированный HTML-отчёт Allure.

## Реализованные проверки

### Создание пользователя (`POST /api/auth/register`)
- Успешное создание уникального пользователя (200, наличие `accessToken`).
- Ошибка при создании уже зарегистрированного пользователя (403, `User already exists`).
- Ошибка при отсутствии обязательных полей `email`, `password`, `name` (403, `Email, password and name are required fields`).

### Логин (`POST /api/auth/login`)
- Успешный вход под существующим пользователем (200, `accessToken`).
- Ошибка при неверном логине или пароле (401, `email or password are incorrect`).
- Ошибка при входе под несуществующим пользователем (401).

### Создание заказа (`POST /api/orders`)
- Успешное создание заказа авторизованным пользователем с валидными ингредиентами (200, наличие `number`).
- Создание заказа без авторизации (200, фактический ответ сервера).
- Ошибка при создании заказа с пустым списком ингредиентов (400, `Ingredient ids must be provided`).
- Ошибка при создании заказа с неверным хешем ингредиентов (500).

## Запуск тестов и генерация отчёта

1. Активировать виртуальное окружение:
   `source .venv/bin/activate`

2. Запустить тесты с сохранением результатов для Allure:
   `pytest --alluredir=allure-results`

3. Сгенерировать HTML-отчёт:
   `allure generate allure-results -o allure-report --clean`

4. Открыть отчёт:
   `allure open allure-report`
